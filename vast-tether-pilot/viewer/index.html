Reading it
The readout at position p is the lens applied to the residual stream at p, so it predicts the token at p + 1. Clicking a caption token opens the step that writes it. Image tokens are read at their own position (what the patch says).
Green cells: the token actually written next. Purple: the tracked word (with plural / singular and the COCO synonyms). COCO object tokens are blue when the object is in the image and orange when it is not. “model” is the model's own top 100 at that position. Logits are rounded to 0.1.

The state is kept in the URL hash, so a view can be bookmarked.
