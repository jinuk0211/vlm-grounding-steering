# 2026-10-28에 이어서 할 일

오늘 완료한 POPE 전체 평가는 다시 생성할 필요가 없다. 최신 원본 clone 점수는 `pope-author-clone/`에, 이전 적용 구현·MMVP는 기존 폴더에 보존했다.

1. `run-state/PAUSED_SUMMARY.json`과 `run-state/RESUME_NOTES_KO.md`를 읽는다. 프로세스 식별 정보·개인 서버 경로·실행 명령을 포함한 상세 원본은 로컬 `outputs/restart-local/`에 보관했다.
2. 사용자 요청에 따라 controller와 worker를 SIGTERM으로 종료하고 GPU0의 모델 메모리를 해제했다. SIGCONT는 사용할 수 없다. 재개 전 서버에서 작업 프로세스가 남아 있지 않은지 다시 확인한다.
3. 인계 문서에 기록한 준비된 재개 스크립트의 `--check`로 기존 JSONL·claims·완료 마커를 검증한 뒤 `--execute`로 이어간다. 원래 controller와 초기 오류 복구용 `resume_author_clone_suite.py`를 그대로 다시 실행하지 않는다. 이미 flush된 응답을 덮어쓰거나 삭제하지 않는다. 이번 마감에는 CPU 검증만 수행했으며 새 모델을 띄우지 않았다. 재개 코드 본체는 서버에 보존돼 있고 이번 GitHub 업로드에는 포함하지 않았다. GPU0 한 장 제한을 유지하고 다른 GPU 작업은 건드리지 않는다.
4. CHAIR 여섯 조건이 각각 500장을 모두 완료하는지 확인한다. 전체 생성·독립 검증·CHAIR 채점이 끝나면 같은 결과 PR에 새 점수를 추가한다.
5. 원래 코드·입력·벡터 해시와 프로토콜을 유지해 완료된 응답을 재사용한다. POPE는 모두 끝났으므로 CHAIR 재개를 위해 POPE를 다시 생성하지 않는다.

실제 정지 방식은 프로세스 종료(SIGTERM)이며 GPU 메모리가 해제됐다. 정확한 종료 시각·프로세스 상태·방법별 수량·미완료 claims는 원본 체크포인트를 따른다. 이후 서버가 재부팅되더라도 보존된 디스크 출력에서 복구해야 한다.

정확한 실행 위치와 명령은 로컬에 보관한 상세 인계 문서에서 확인한다.

현재 판단: GrAInS 원본 clone의 POPE는 FP32 Base 대비 Acc +0.10%p, F1 +0.54%p이나 차이의 95% 구간은 0을 포함한다. CHAIR 점수는 미완료 상태이므로 쓰지 않는다. 이번 업로드에서 새로운 튜닝이나 평가 범위를 추가하지 않았다.
