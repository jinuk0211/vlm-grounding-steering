# RUDDER 원본 clone의 작은 POPE 변화에 대한 확인

원본 Qwen POPE 설정 layer1/alpha8을 Gemma E4B에 적용했다. 저자 함수 호출은 확인했으며, 저자 모델·환경 전체 재현을 뜻하지 않는다.

전체3,000문항에서 Base와 최종 답이 같은 문항은2,995개다. 다른5개 중 오답→정답2개, 정답→오답3개로 정답이1개 줄었다.

별도 개발6장 CPU FP32 prefix 진단의 중앙값: gate0.9617, attention 출력의 상대 변화6.494%, 정규화 뒤 상대 변화4.380%, residual과 합친 뒤 상대 변화4.358%. 개입이 완전히 사라진다는 설명은 이 진단에서 지지되지 않았다.

이 CPU 진단은 실행 중인 GPU BF16 모델의 직접 기록이 아니며 최종 답변 logits를 측정하지 않았다. 따라서 층·강도의 적합성, 모델의 실제 비효과, 다른 구현 문제가 각각 얼마나 기여했는지는 아직 분리하지 못했다.

다음 검증은 테스트 정답을 사용하지 않는 개발 입력에서 첫 토큰 Yes/No logits와 층별 개입 전후 크기를 측정하는 것이다.
