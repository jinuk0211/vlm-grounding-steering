GrAInS는 Base FP32, 나머지 방법은 Base BF16과 비교한다. 공식 evaluate.py와 독립 재채점이 일치했다. 테스트 이미지와 개발 이미지 해시 중복0개다.

CHAIR 고정500장·최대512토큰 평가는 POPE 종료 후 계속했으며, 오늘 마감 시 출력 보존·프로세스 종료 상태로 전환했다. 현재 상태는 상위 README와 체크포인트를 참고한다. POPE의 부분 집계가 아니라 전체3,000문항 집계이며 전체 벤치마크 완료를 뜻하지 않는다.

독립 재검증: 전달된 여섯 조건의 응답을 각각 3,000개씩 다시 채점해 공식 보고서와 일치함을 확인했다. GrAInS와 FP32 Base는 같은 문항 ID·정답·프롬프트·이미지 해시·정밀도로 비교했다.

GrAInS는 FP32 Base 대비 답이 83개 달랐고, 오답→정답 43개, 정답→오답 40개로 정답이 3개 늘었다. Acc +0.10%p, F1 +0.54%p, Precision −1.84%p, Recall +2.67%p다.

이미지 단위 paired bootstrap 95% 구간: Acc 차이 −0.50~+0.70%p, F1 차이 −0.08~+1.19%p. 두 구간 모두 0을 포함하므로 뚜렷한 개선이 입증됐다고 해석하지 않는다.
