# E0'·E1: 캡션 쓰는 순간의 검증 신호와 steering (2026-10-30)

결과 파일은 서버 `outputs/verify-probe-20261030/`에 있습니다.

## E0': 물체를 쓰기 직전 hidden state로 "물어보면 No라고 할지"를 맞히는가

스크립트: `scripts/verify_probe_collect.py`, `scripts/verify_probe_analyze.py`

- 방법: Base 캡션을 teacher forcing으로 넣고, 물체 첫 토큰을 예측하는 위치의 hidden state를 전 층에서 뽑았습니다. 같은 캡션을 회색 이미지로도 넣었습니다.
- 라벨: caption-selfcheck의 margin < 0(T1)과 hallucinated(T2)입니다.
- 학습: 이미지 단위 5-fold CV로 층별 로지스틱 probe를 학습했습니다. 표준화 → PCA 256 → L2이고, L2 강도는 내부 CV로 정했습니다.
- 단위: (이미지, 물체)마다 첫 언급 1개입니다.

| | Qwen 100장 | Qwen 500장 | Gemma 100장 | Gemma 500장 |
|---|---|---|---|---|
| 표본(물체) | 352 | 1,105 | 342 | 1,269 |
| T1 실제 이미지 F1 (최고층) | 0.80 (L25) | 0.84 (L25) | 0.72 | 0.86 (L41) |
| T1 회색 이미지 F2 | 0.67 | 0.80 | 0.72 | 0.80 |
| T1 F1 − F2 [95% CI] | +0.13 [0.08, 0.17] | **+0.04 [0.01, 0.07]** | +0.005 | **+0.06 [0.04, 0.08]** |
| T1 log p·순서·위치 (F3) | 0.68 | 0.73 | 0.61 | 0.66 |
| T2 F1 / 질문 상한 | 0.82 / 0.92 | 0.88 / 0.94 | 0.82 / 0.88 | 0.89 / 0.90 |
| 사전 규칙 판정 | 애매 | 언어 prior | 언어 prior | 애매 |

- 100장 subset은 환각이 1개 이상 있는 캡션만 골랐습니다. 이 subset에서 보인 Qwen의 이미지 신호 +0.13은 500장에서 +0.04로 줄었습니다.
- 500장 기준으로 hidden state는 "물어보면 부정할 물체"를 AUROC 0.84–0.86으로 맞힙니다. 하지만 그 대부분은 회색 이미지로도 맞힐 수 있습니다(0.80). 즉 언어 prior입니다.
- 이미지가 더하는 몫은 0.04–0.06으로, 유의하지만 작습니다.

## E1: 같은 위치에 개입하면 환각 물체만 떨어지는가

스크립트: `scripts/verify_probe_e1.py`

- 대상: E0'와 같은 100장, 같은 위치(물체 첫 토큰을 예측하는 query)입니다. 모든 물체 위치에 동시에 개입했습니다.
- 측정:
  - 물체 첫 토큰의 Δlog p
  - top-1 상실률(개입 전에는 1위였는데 개입 후 아닌 비율)
- 비교한 개입:
  - **probe 방향**: probe 방향 u는 100장과 겹치지 않는 약 370–390장으로 학습했습니다. 층도 그 데이터의 CV로 골랐습니다(Qwen L23, Gemma L26). 테스트 100장에서 u 사영의 AUROC는 Qwen 0.79, Gemma 0.82입니다. 개입은 h − kσu입니다.
  - **같은 크기의 random 방향**: 대조군입니다.
  - **재읽기**: 이미지 key의 attention logit에 +β를 더합니다(β = 1, 2, 3; 전층 / 후반 층).

| 개입 | Qwen Δlog p 환각 / 정답 | Qwen top-1 상실 환각 / 정답 | Gemma Δlog p 환각 / 정답 |
|---|---|---|---|
| probe −8σ | −0.06 / +0.01 | 8% / 6% | −0.02 / 0.00 |
| probe −16σ | −0.16 / −0.03 | 16% / 9% | −0.14 / −0.08 |
| probe −32σ | −0.66 / −0.23 | 42% / 19% | −0.60 / −0.42 |
| random 32σ | −0.44 / −0.21 | 26% / 14% | −0.18 / −0.09 |
| 재읽기 β=3 (전층) | −0.10 / −0.10 | 20% / 12% | −0.58 / −0.46 |

- **환각 토큰은 원래 확신도가 낮습니다**(base log p: Qwen −1.02 vs 정답 −0.62). 그래서 어떤 방향으로 흔들어도 환각 쪽이 더 떨어집니다. random 방향도 큰 크기에서는 "선택적"으로 보입니다.
- **probe가 random보다 나은 정도**(선택성 차이)는 다음과 같습니다.
  - Qwen: 8σ에서 −0.045 [−0.086, +0.002], 16σ에서 −0.067 [−0.152, +0.016], 32σ에서 −0.200 [−0.372, −0.031]. 32σ에서만 유의합니다.
  - Gemma: 모든 강도에서 유의하지 않습니다.
- **재읽기는 Qwen에서 환각과 정답을 똑같이 떨어뜨립니다.** Gemma에서는 환각 쪽이 조금 더 떨어지지만 유의하지 않습니다.
- **비교 기준**: 질문 방식(self-check)은 환각의 76%를 부정하고 정답은 7%만 부정합니다. 반면 probe −32σ는 환각 42%와 함께 정답도 19%를 1위에서 떨어뜨립니다.
- **Gemma의 구조 문제**: Gemma 4 E4B는 24층부터 KV를 앞 층과 공유합니다. 그래서 L26에서 residual을 바꿔도 이후 토큰에는 전달되지 않습니다(다른 토큰 KL = 0). 디코딩에 넣으면 그 위치의 다음 토큰에만 영향을 줍니다.

## Query-anchored attention step 0: 환각 직전의 이미지 attention은 모양이 다른가

스크립트는 `scripts/verify_probe_attn.py`이고, 결과는 서버 `outputs/query-anchor-step0-20261030/`에 있습니다.

- **측정**: 물체 첫 토큰을 예측하는 query에서, 층·헤드마다 이미지 key에 대한 attention의 네 가지 값을 쟀습니다.
  - 양(mass)
  - 정규화 엔트로피
  - 상위 1% 집중도
  - 캡션 공통 sink 토큰 비중
- **대상**: Base 캡션 전부(Qwen 468장, Gemma 489장)의 물체 첫 언급입니다.
- **사전 규칙**: 헤드 평균을 주 층(Qwen 전층, Gemma full-attention 7층)에 걸쳐 평균한 엔트로피 또는 sink 비중을 봅니다. 위치를 맞춘 차이의 CI가 0을 제외하고, 위치 보정 AUROC가 0.45–0.55 밖이어야 통과입니다.

| 지표 (위치 보정 AUROC, 환각 쪽이 높으면 > 0.5) | Qwen | Gemma |
|---|---|---|
| 양 (mass) | 0.37 | 0.43 |
| 엔트로피 | 0.51 | 0.49 |
| 상위 1% 집중도 | 0.51 | 0.49 |
| sink 비중 | 0.52 | 0.49 |
| **사전 규칙 판정** | 차이 없음 → 접음 | 차이 없음 → 접음 |

**사후 확인(탐색적)**: 헤드별로 보면 평균에서 상쇄되던 차이가 있습니다. 이미지의 절반에서 상위 10개 헤드를 고르고, 나머지 절반에서 그 헤드들의 합산 점수 AUROC를 쟀습니다. 분할은 5회입니다.

| 통제 | Qwen 엔트로피 / 상위 1% / sink / 양 | Gemma 엔트로피 / 상위 1% / sink / 양 |
|---|---|---|
| 위치만 보정 | 0.68 / 0.66 / 0.49 / 0.70 | 0.71 / 0.72 / 0.72 / 0.63 |
| + 양(mass) 제거 | 0.68 / 0.66 / 0.50 / — | 0.68 / 0.69 / 0.68 / — |
| + 같은 물체 안에서만 비교 | **0.62 / 0.61 / 0.53 / 0.68** | **0.59 / 0.57 / 0.51 / 0.60** |

- **"환각 query가 sink 이미지 토큰으로 흐른다"는 가설은 두 모델 모두 지지되지 않습니다.** Gemma의 sink 효과(0.72)는 물체 단어 종류 때문이었고, 같은 물체 안에서 비교하면 0.51로 사라집니다.
- **남는 것 1 — 양 차이**: 같은 물체라도 환각 직전에는 이미지를 덜 봅니다(Qwen 0.68, Gemma 0.60). 하지만 E1에서 양을 늘리는 재읽기는 선택적이지 않았습니다. 상관은 있지만 손잡이는 아닙니다.
- **남는 것 2 — 약한 모양 차이**: 일부 중후반 헤드(Qwen L21–24)가 환각 직전에 소수 이미지 토큰에 더 집중합니다(0.57–0.62).
- **검출 성능 비교**: 이 지표들로 환각을 검출하는 성능(0.6–0.7)은 hidden state probe(0.84–0.86)나 직접 질문(0.90–0.94)보다 낮습니다.

## 한계
- teacher forcing 위치 단위의 측정입니다. 실제 디코딩(CHAIR 500장)은 돌리지 않았습니다.
- 물체 위치를 미리 안다고 가정했습니다(oracle 위치). 실제로는 게이트가 필요합니다.
- E0'의 최고층은 같은 데이터로 골랐으므로 약간 낙관적입니다. E1의 방향과 층은 테스트 100장과 겹치지 않는 데이터로 정했습니다.
