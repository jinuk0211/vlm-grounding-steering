# 대상에 결합된 의미를 읽는 steering — 설계 후보

현재 논의한 방법론을 별도로 보존한 문서다. **실행 코드, 학습된 reader, 성능 검증 결과는 아직 없다.**

[전체 설계 (English)](README.md)

![Proposed inference mechanism](method.png)

이미지의 시각적 근거와 현재 decoder 상태를 따로 읽고, 특정 물체·속성에 해당하는 성분을 선택해서 작은 개입을 적용한다. 목표는 버스의 색에 관한 판단을 고치면서 자동차에 관한 정보는 보존하는 것이다.

- **이 후보의 학습:** VLM 가중치는 고정하고 reader를 별도로 학습한다. Training-free 방법이 아니다. 추가 학습 없는 대안과 이 후보 중 무엇을 최종 채택할지는 확정하지 않았다.
- **LatentLens:** 현재 설계에 직접 통합하지 않았다. 그림의 Semantic reader를 LatentLens 구현으로 해석하면 안 된다.
- **Read의 기여:** 물체와 속성의 결합을 읽고, 해당 사실의 변화와 내부 성분의 변화가 대응하는지 검증한다. QA 정확도나 reader 자체 점수만으로 의미 성분이 입증됐다고 주장하지 않는다.
- **선택적 개입:** 목표 사실의 실제 출력 변화와 다른 사실의 보존을 함께 확인한다. 근거가 불확실하거나 이미 충분히 지지되면 개입하지 않는다.
- **첫 실험:** Qwen2.5-VL의 한 decoder layer에서 통제된 색 속성 QA로 기전을 확인한다. 이후 물체 존재 여부, POPE, CHAIR로 확장하며 recall·출력 길이·지연도 측정한다.
- **후속 확장:** 개입 후보의 효과·부작용 예측기는 현재 구현된 구성 요소가 아니다.

영어 그림은 제안한 추론 과정을 보여주는 개념도다. 예시의 출력은 측정된 실험 결과가 아니다. 이 문서의 신규성이나 성능 향상은 검증되지 않았다.
